# Apex / Formula Rush

A small, original browser racing game inspired by open-wheel motorsport. It is not an official Formula 1 game and does not use F1 team or driver branding.

## Play

Open `index.html` in a modern browser. Press **Enter** to start a three-lap race.

- **W / ↑** accelerate
- **S / ↓** brake
- **A / ←** steer left
- **D / →** steer right
- **Shift** boost while accelerating
- **R** restart

The game also includes touch controls on smaller screens, three rival cars, a circuit map, lap timing, and off-track slowdown. It runs entirely in the browser and needs no API key or account.
